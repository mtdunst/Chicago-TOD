What should each station become?

Every CTA and Metra station in Chicago gets a best-fit type, the reasons behind it, and why the other types fit less well. Switch to Transit Future to see how better service would change the answer.

Circle size shows room for new homes on underused land. An outlined circle marks a station whose type changes in Transit Future. Hollow diamonds are stations that don't exist yet.

The six types

Each station is scored from 0 to 100 against all six. The highest score is its best fit. Scores compare stations to each other, so a 70 means a station fits that type better than most, not that it is 70% suited.

What Transit Future assumes

Transit Future puts the most serious service proposals on the table at once. Service is never cut: each line keeps today's schedule wherever that is already better than the target.
